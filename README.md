This repository is associated with the article:

> **PAN-GENOMIC EVIDENCE FOR NICHE-DRIVEN RESISTOME AND VIRULOME DIVERGENCE IN *Acinetobacter baumannii* FROM ANIMAL, ENVIRONMENTAL, HUMAN AND HOSPITAL ABIOTIC SOURCES**

The repository contains the genomic datasets, genome annotations, resistance and virulence analyses, gene grouping files, and statistical analyses performed in the study.

## Repository structure

### `database_tables/`

Contains two genome tables obtained from the BV-BRC and NCBI databases. These genomes were used in the study.

### `genomes_by_group/`

Contains genome tables separated according to the source group:

* Animal
* Environmental
* Human
* Hospital

These are the filtered genomes used as input for the downstream bioinformatics analyses.

### `genome_annotations_by_group/`

Contains the genome annotations and their corresponding functional analyses, organized according to each source group.

### `rgi_output_tables/`

Contains the resistance gene identification tables generated by RGI, separated according to each source group.

### `vfdb_output_tables/`

Contains the virulence factor identification tables generated using VFDB, separated according to each source group.

### `gene_grouping/`

Contains two files describing the grouping of genes identified in the resistance and virulence analyses, respectively.

### `statistical_tests/`

Contains the files related to the statistical analyses, organized into two subdirectories:

* `resistance/`
* `virulence/`

Each subdirectory contains:

#### `statistical_input/`

Input file used for the statistical analysis, containing the count of each gene in each source group.

#### `statistical_analysis.R`

R script used to perform the statistical tests applied in the study.

#### `results_fisher_test.xlsx`

File containing the results obtained from the statistical analysis.
